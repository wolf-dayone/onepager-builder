# DAYONE Onepager — Live-Prototyp

Testumgebung für den DAYONE-Onepager-Skill (`dayone-onepager`). Hier laufen Design- und
Verhaltens-Fixes aus dem Figma-Abgleich live durch, bevor sie in den Skill zurückwandern.

- `index.html` — Testseite 1: "Kekse für alle" (Weekly-Beispiel, deckt Hero, Sticky-Liste,
  Divider, Karten-3er, Kennzahlen, Zitat, Karten-Karussell, Footer ab)
- `umzug/index.html` — Testseite 2: "Neuer Standort" (Büroumzug-Beispiel, deckt Agenda,
  Matrix-2x2, Prozess-Schritte, Roadmap-Timeline, Tabelle, Team-Grid, Facts & Figures ab —
  Module, die zuvor nur im Katalog dokumentiert, aber nicht als Code vorhanden waren)
- `starter.html` — generisches Skill-Template (Platzhalter), 1:1 aus dem Skill
