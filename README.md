# DAYONE Onepager — Live-Prototyp

Testumgebung für den DAYONE-Onepager-Skill (`dayone-onepager`). Hier laufen Design- und
Verhaltens-Fixes aus dem Figma-Abgleich live durch, bevor sie in den Skill zurückwandern.

- `index.html` — aktuell laufende Testseite: "Neuer Standort" (Büroumzug-Beispiel).
  Deckt Agenda, Matrix-2x2, Prozess-Schritte, Roadmap-Timeline, Tabelle, Team-Grid und
  Facts & Figures ab — Module, die zuvor nur im Katalog dokumentiert, aber nicht als
  Code vorhanden waren.
- `kekse/index.html` — vorherige Testseite: "Kekse für alle" (Weekly-Beispiel). Deckt
  Hero, Sticky-Liste, Divider, Karten-3er, Kennzahlen, Zitat, Karten-Karussell, Footer ab.
- `starter.html` — generisches Skill-Template (Platzhalter), 1:1 aus dem Skill.
